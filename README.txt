6教科ラボ　アップロード用データ

■ フォルダの中身
  index.html        … トップページ（6教科の入口）
  math/index.html   … 数学Ⅰ ラボ
  koten/index.html  … 言語文化 ラボ（古文・漢文）
  eigo/index.html   … 英文法 ラボ
  chem/index.html   … 化学基礎 ラボ
  butsuri/index.html … 物理基礎 ラボ
  chiri/index.html  … 地理総合 ラボ
  hoken/index.html  … 保健 ラボ
  robots.txt / .nojekyll … 検索エンジンに載せない設定と、GitHub Pages 用の設定ファイル（そのまま置いてください）

  ※ フォルダ名は変えないでください。トップページのリンクが切れます。
  ※ 各ラボは1ファイルで完結しています（画像も中に入っています）。

■ GitHub Pages で公開する場合
  1. GitHub で新しいリポジトリを作る（Public）
  2. 「Add file」→「Upload files」で、このフォルダの中身をすべてドラッグ＆ドロップして「Commit changes」
     （.nojekyll は見えないことがあります。なくても表示はできます）
  3. Settings → Pages → Branch を「main」「/(root)」にして Save
  4. 数分後、https://（ユーザー名）.github.io/（リポジトリ名）/ でトップページが開きます

■ Netlify で公開する場合
  Netlify の「Deploy manually」の画面に、このフォルダごとドラッグ＆ドロップします。

■ 学習の記録について
  記録は各端末のブラウザに保存されます。トップページとラボを同じサイトに置くと、
  トップページの各カードに生徒それぞれの達成率が表示されます。
